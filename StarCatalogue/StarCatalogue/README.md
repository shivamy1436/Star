
# Star Catalogue System

A Java-based Star Catalogue Management System.

## Modules

1. Star Data Management
2. Hash Table with Chaining
3. AVL Tree with Four Rotations
4. Fixed Sliding Window Dip Detector
5. Graph using Adjacency List
6. Depth First Search (DFS)
7. 12 Option Menu
8. 33 Automatic Test Cases

## Technologies

- Java
- Data Structures
- Algorithms
- Object Oriented Programming

## How to Run

Compile:

```bash
cd src
javac *.java
```

Run Main:

```bash
java Main
```

Run Tests:

```bash
java TestRunner
```

- ArrayList
